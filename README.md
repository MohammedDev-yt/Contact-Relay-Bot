## ✨ Features

- 📩 **Direct User-to-Owner Relay:** Users send text, photos, videos, voice notes, or documents to the bot and receive an instant forwarding confirmation.
- ↩️ **Reply-to-Respond Bridge:** Simply reply to any forwarded message or user header card in your private chat to deliver your exact message back to the user.
- 🎨 **Blockquote UI & Interactive Panels:** Clean HTML blockquote formatting with **Updates**, **Help**, and **About** inline buttons, **Home** & **Close** navigation, and optional start banner image support.
- 🔒 **Multi-Channel Force Subscription:** Require users to join configured channels via `/addforcesub`, `/removeforcesub`, and `/forcesublist` with a **Try Again** verification button.
- 🚫 **Block / Unblock System:** Ban abusive users with `/block` (by reply or user ID) and restore access with `/unblock`.
- 📢 **Broadcast & Telemetry:** Send messages to all saved users with `/broadcast`, view counts via `/stats`, and check live uptime with `/botuptime`.
- 🗄️ **MongoDB Persistence:** Stores users, message mappings, blocked users, and ForceSub channels across restarts and redeploys.
- 🌐 **24/7 Flask Keep-Alive Server:** Built-in Flask HTTP endpoint ready for Render and external uptime monitors.

| Variable | Description |
| :--- | :--- |
| `API_ID` | Telegram API ID from my.telegram.org |
| `API_HASH` | Telegram API Hash from my.telegram.org |
| `BOT_TOKEN` | Telegram Bot Token from @BotFather |
| `OWNER_ID` | Owner numeric Telegram User ID |
| `MONGO_URI` | MongoDB connection string |
| `START_IMAGE_URL` | Optional image URL shown on /start |
| `BOT_NAME` | Bot display name in About menu (Default: Aero Contact Relay) |
| `BOT_VERSION` | Bot version label in About menu (Default: v3.3) |
| `UPDATES_CHANNEL_URL` | Updates channel URL (Default: https://t.me/Aero_Unity) |
| `REPO_URL` | Repository / project link |
| `DEPLOY_STATUS_URL` | Deployment status link |
| `PORT` | Web server port (Default: 8080) |
